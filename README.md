# wordle-game
A Wordle-inspired word guessing game built using HTML, CSS, and JavaScript, featuring interactive gameplay, word validation, and real-time feedback.

## Features

* Interactive word guessing gameplay
* Real-time feedback for correct and misplaced letters
* Limited attempts to guess the word
* Responsive and user-friendly interface
* Built using vanilla JavaScript

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Play

1. Enter a valid word.
2. Press Enter to submit your guess.
3. Letter colors indicate:

   * 🟩 Correct letter in the correct position
   * 🟨 Correct letter in the wrong position
   * ⬜ Letter not present in the word
4. Guess the word within the allowed attempts.
